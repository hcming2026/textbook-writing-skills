# 审校标准 v1.1

> 适用：`textbook-reviewer` 的评分与判定依据
> 状态：v1.1 待学科专家审定；权重为建议值，可按项目调整（SOP 阶段 5）
> v1.1 变更：修正禁用词表条目误引（原写 YY-06，实为语言风格§六）；补 YY-21 脚本项；新增第五节「只能人工判的项」

## 一、五维评分（每项 1–5 分，加权）

| 维度 | 看什么 | 权重 | 5 分标准 | 3 分标准 | 1 分标准 |
|---|---|---|---|---|---|
| 科学性 | 概念、事实、结论、数据是否准确且可溯源 | 30% | 所有数据带口径来源；概念定义与主流文献一致；无过度推论 | 结论正确但个别数据缺来源 | 出现事实错误或未定义概念 |
| 体例符合度 | 六栏齐全、顺序正确、篇幅在区间、图表编号规范 | 20% | 全部符合 `体例规范.md` | 栏目齐全但篇幅超区间 ≤20% | 缺栏或栏目顺序错 |
| 学段适切性 | 难度、语言、案例是否对得上本科高年级 / MBA | 20% | 参数落在 `学段适配.md` 区间；难度递进可检出 | 参数基本符合，个别段落过难/过浅 | 用错学段参数（如 MBA 稿件写了完整推导） |
| 练习质量 | 是否分层、是否对齐 LO、是否有参考答案 | 15% | 三层齐全、比例合规、每题挂 LO、拓展题有评分要点 | 分层但比例失衡或少量题缺 LO | 只有一层或无参考答案 |
| 语言规范 | 标点、数字、用词、禁用词 | 15% | 无禁用词；标点数字全合规；句长段长在限 | 有 3–5 处可修问题 | 大量口语化或违反禁用词表 |

**加权公式**：`总分 = Σ(维度分 × 权重)`。建议通过线 **4.0**（SOP 阶段 5）。

## 二、一票否决项（出现任一即判不通过，不进入加权）

| 编号 | 否决项 | 说明 |
|---|---|---|
| SJ-X1 | 思想性、政治性问题 | 涉及国家主权、民族、宗教、历史评价的错误表述 |
| SJ-X2 | 科学性错误 | 概念定义错误、公式错误、数据自相矛盾 |
| SJ-X3 | 版权问题 | 整段改写、拼接或复述样本教材原文；未授权引用 |
| SJ-X4 | 编造事实 | 虚构数据、虚构文献、虚构政策文件且未标【待核实】 |
| SJ-X5 | 违反 GB/T 15834 / 15835 | 系统性标点或数字用法错误（≥10 处） |

## 三、可脚本判定的项（`scripts/check_draft.py` 覆盖）

| 检查项 | 判定 | 依据 |
|---|---|---|
| 六栏齐全与顺序 | 标题匹配 | TY-06 ~ TY-11 |
| 各栏字数是否在区间 | 中文字符计数 | 学段适配参数表 |
| 练习三层是否齐全、比例是否合规 | 小标题匹配 + 计数 | LX-02 |
| 每题是否挂 LO | 正则 `LO-\d+-\d+` | LX-01 |
| 是否含禁用词 | 词表匹配 | 语言风格 §六 禁用词表（总则 YY-01） |
| 是否含「显然/众所周知」等跳跃词 | 词表 | YY-11 |
| 单句是否超 60 字 | 句读切分 | YY-03 |
| 单段是否超字数 | 空行切分 | YY-02 |
| 图表是否有编号与来源 | 正则 `图 \d+\.\d+\.\d+` / `资料来源` | TY-04 / TY-14 |
| 是否出现【待核实】 | 正则 | SOP 阶段 4 |
| 数字是否用空格分节（`1 098`） | 正则 `\d{1,3}(?: \d{3})+` | YY-21 |

脚本只出「事实性违规清单」，不出分数。分数由 `textbook-reviewer` 依本文件给出，并附证据行号。

## 四、审校报告必备结构

```
1. 结论：通过 / 有条件通过 / 不通过
2. 加权得分：各维度分 + 总分
3. 否决项核查：逐条 X1–X5 是否触发
4. 事实性违规清单：脚本输出，按栏分组
5. 需人工判断的问题：每条给位置 + 问题 + 改法建议
6. 修改后再审要求：需重跑的检查项
```

## 五、审校的边界

- 审校**不改稿**。只出问题清单与改法建议，改稿由作者执行或另起一轮 `unit-writer`。
- 审校**不评「写得好不好」**。文学性评价不进五维，避免主观分污染。
- 审校**必须给出证据位置**（栏目 + 段落序号或引文前 10 字），无位置的意见视为无效。

## 六、只能人工判的项（脚本不覆盖，须写进报告第四节第 5 条）

> 这些条目看的是「这一段说了什么」，不是字符模式。写正则只能抓到「由上可见」这类连接词，而恰恰是只写连接词不写内容的段落最该被判不合格。

| 检查项 | 判定要求 | 依据 |
|---|---|---|
| 导语是否四段推进 | 逐一核对：铺背景 / 反转出问题（把好处翻成麻烦）/ 落任务 / 给意义。缺第②段的，直接判「导语不合格」，不进加权 | TY-06 |
| 正文推进链是否完整 | 是否「概念 → 模式 → 机制 → 边界」四步俱全。**最常见缺陷是缺「模式」**——只给一种模型（或只给一条路线）就往下走，读者会把它当唯一解 | TY-07 |
| 候选之间是接力还是并列 | 找到「换下一个候选」的那个转折句，看它是不是由前一个候选的**缺点**引出来的。写成「常用的方法有 A、B、C」然后逐个介绍，判不合格——读者得到清单，不知道为什么要换 | TY-07 |
| 每个候选的缺点写得实不实 | 缺点条数少于优点、或只写「存在一定局限性」，判不合格。缺点不实，下一个候选就出不来 | YY-27 |
| 候选超过 4 个时有没有全景段 | 有没有一段把全族名字点全、给分类依据、声明「多数情况综合运用」。只讲两三个却不提还有别的，判不合格 | YY-26 |
| 章末参考文献是否只用不列 | 逐条回查 `[n]` 在正文/脚注中有无对应引用。凑书单（列了正文没提过的书）按 TY-19 记不合格 | TY-19 |
| 内容提要是否复述论证 | 提要只该给结论，不该重走推理。出现「首先……然后论证了……」即视为复述 | TY-16 |
| 定义阵列有没有「为什么列」 | 列 3 条以上定义前，是否交代了为什么列、按什么标准列 | YY-18 |
| 学术史四要素是否齐全 | 人 / 年 / 刊 / 结论，缺二即不可核查，记问题 | YY-23 |
| 分域扫描是否落到例证 | 每段是否有具体例子或可署名引文；只有「各领域都重视 X」的判不合格 | YY-24 |
| 收口段是否三件套 | 提炼共性 / 指出覆盖关系 / 说明增量，至少要有前两项 | YY-25 |
| 多套框架并列后有没有选定 | 出现多个框架/模型/流派时，是否选定一套作为本书的，并说明选择理由。停在「以上各有道理，供读者参考」判不合格——这是把判断责任推给读者 | TY-20 |
| 分级分类有没有给成因 | 每一层是否说清了按什么矛盾划分。只有层级没有成因，判「标签式分类」 | YY-29 |
| 争议概念有没有收束 | 是否按「争议 → 共识 → 现实证据 → 分歧」写。只列观点不作收束，判不合格 | YY-30 |
| 逐段问「凭什么」 | 抽 5 段，逐段问「拿掉它，读者会失去什么判断能力」。答「只是少知道一个事实」超过 3 段，判判断密度不足 | YY-28 |

**注意**：这些项一旦判不合格，须在报告里给出**引文前 10 字 + 所在栏 + 段序**。只写「导语写得不好」的意见，按本文件第四节第 5 条视为无效意见。
