# 学段适配规范 v1.0

> 适用：管理科学与工程 · 本科高年级（大三、大四）/ MBA
> 依据：阶段 2 对比（E1 学术纵深 vs E4 明确面向 MBA 的实战化） + 本项目定位
> 状态：v1.0，参数值即 `outline-designer` 与 `unit-writer` 的默认取值来源

## 一、学习者画像

| 维度 | 本科高年级 | MBA |
|---|---|---|
| 前置知识 | 修过管理学、统计学基础；缺真实业务决策经验 | 有 3 年以上管理或专业经验；理论零散、缺体系 |
| 学习动机 | 应付考试 + 建立专业身份 | 解决手上真实问题 + 换取晋升与话语权 |
| 主要障碍 | 无法把模型对到现实 | 无法接受「只有结论没有过程」，也不耐烦过度推导 |
| 对教材的期待 | 「讲清楚」，能自学 | 「能马上用」，能带到会议室 |

**由此决定的两条主线**：本科高年级走「可复现的推导」，MBA 走「可辩的决策」。

## 二、参数对照表（下游直接取用）

| 参数 | 本科高年级 | MBA | 说明 |
|---|---|---|---|
| 导语字数 | 150–250 | 200–350 | MBA 需要更长情境铺垫 |
| 正文字数 | 3000–4500 | 2500–3500 | MBA 正文收敛，把空间让给案例 |
| 案例字数 | 800–1200 | 1200–2000 | |
| 每章页数 | 30–50 | 20–35 | |
| 每章节数 | 4–5 | 3–4 | |
| 单课学时 | 2 或 4 | 2 或 4 | |
| 图位数量/课 | 2 | 1 | MBA 靠文字情境，本科靠图解结构 |
| 练习三层比例 | 5:3:2 | 4:3:3 | MBA 提高/拓展占比更大 |
| 公式与推导 | 正文内完整推导 | 正文只留方向与结论，推导入附录 | |
| 案例真实度 | 可为教学化虚构，但数据必须自洽 | 须贴近真实决策，含多方立场与信息不对称 | |

## 三、难度曲线

| 编号 | 规则 |
|---|---|
| XD-01 | 同一单元内，课与课的认知层级必须递进：首课「理解」，中课「应用/分析」，末课「评价/创造」。不得四课都停在「理解」。 |
| XD-02 | 全书难度不呈锯齿：不得出现「简—难—简—难」，须为单调上升或阶梯上升（每 2–3 章上一个台阶）。 |
| XD-03 | 本科高年级：每章至少 1 处「完整算例」（给数据、给步骤、给答案、给答案的适用边界）。 |
| XD-04 | MBA：每章至少 1 处「无标准答案的两难」，并要求学习者表态与说明依据。 |
| XD-05 | 学段参数不得只改标题：同一主题的两个学段版本，导语、案例、练习三层都必须有可检出的差异（字数、题量、设问层级）。 |

## 四、两学段的具体改写示范

同一知识点「牛鞭效应」：

**本科高年级**（给推导）

> 设零售商需求方差为 σ²，订货提前期为 L，则当 L 从 1 周增至 4 周时，上游制造商观察到的需求方差放大约 √L 倍。推导如下：…
> 练习：给定 σ=50、L=1/2/4/8，计算并画出放大倍数曲线。

**MBA**（给判断）

> 你所在的快消企业，区域仓的订单波动是终端零售波动的 3 倍。CEO 问：是不是把安全库存整体提高 30% 就能解决？
> 你的回答应当是：不能，因为放大来自提前期与批量规则，不是库存水平。你要动的是……
> 练习：请给出一份不超过 200 字的答复要点，并说明你会先做哪个试点。

## 五、判定清单（审校时逐项过）

| 检查项 | 本科高年级 | MBA |
|---|---|---|
| 导语是否给出情境 | 需要 | 必须是真实决策情境 |
| 正文是否含完整推导 | 必须 | 不必须，但必须给方向理由 |
| 案例是否有决策者与约束 | 需要 | 必须，且含立场冲突 |
| 练习是否要求计算 | 必须有 | 允许为判断与方案 |
| 是否出现「显然」跳过推理 | 禁止 | 禁止 |
| 是否有可带走的工具（清单/模板/决策树） | 不必须 | 每章至少 1 个 |
