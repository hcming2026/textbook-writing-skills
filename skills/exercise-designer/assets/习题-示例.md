# 信息系统与信息资源管理 第2单元第3课 练习

> 学段：MBA ｜ 对应目标：LO-2-3
> 本文件由 exercise-designer 产出，题号全篇连续。

### 基础层

1. [LO-2-3] 用自己的话说明"切换窗口"的含义，并举出一个乳企之外行业的窗口例子。
2. [LO-2-3] 判断并说明理由：一次性替换的总成本通常高于分步替换。
3. [LO-2-3] 列出"封装延寿"路线在三年后必然面对的两个问题。
4. [LO-2-3] 说明"可逆性排序"与"按重要性排序"在决策结果上的差别，各举一例。

### 提高层

5. [LO-2-3] 用表 2.3.1 的四个维度，给一家年营收 3 亿元的区域乳企重新打分，并说明哪一项的打分与该表不同、为什么。
6. [LO-2-3] 案例中三方各自的最优顺序是什么？请分别写出，并指出三者之间最小的那个共识。

### 拓展层

7. [LO-2-3] 为案例企业写一份不超过 300 字的决策建议，须包含顺序、每一步的验收指标、以及被放弃路线的理由。
   交付物：一页 A4 备忘。
   评分要点：合格 = 顺序有依据且给出验收指标；优秀 = 额外说明若预算削减 40% 时的调整方案。
8. [LO-2-3] 访谈一位你所在企业的 IT 负责人，问清他们上一次系统切换的真实窗口是怎么定的。整理成 200 字的情境描述。
   交付物：200 字情境 + 一句"这个窗口的假设是否成立"的判断。
   评分要点：合格 = 有具体时间与约束；优秀 = 指出该窗口设定中的隐含假设。
9. [LO-2-3] 设计一个"切换失败后的退回预案"，须包含触发条件、退回步骤、责任人三部分。
   交付物：一张三列矩阵。
   评分要点：合格 = 三项齐全且触发条件可观测；优秀 = 补充退回本身的成本估算方法。
