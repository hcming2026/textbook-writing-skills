# 练习与评价设计（exercise-designer）

## 适用场景

- 一节课写完，需要配套练习。
- 已有正文，需要补拓展层的方案设计题。
- 已有题库，需要按三层重排并补 LO 标注。

不适用：写正文（→ `unit-writer`）、审校成稿（→ `textbook-reviewer`）、出整卷考试题（本系列不覆盖考试命题）。

## 输入要求

| 输入 | 说明 | 缺失处理 |
|---|---|---|
| 该课正文或知识点清单 | 题目必须源自正文内容，不得超纲 | 必给 |
| 学习目标 `LO-x-y` | 每题挂哪条目标 | 必给。只有正文没有 LO 时，先回 `curriculum-mapper` |
| 学段 | 决定三层比例（本科 5:3:2 / MBA 4:3:3） | 必问 |
| 题量 | 默认 8–12 题 | 用默认 |

## 执行步骤

1. **读规范**。读 `references/练习设计.md`，确认三层定义、题型配比与硬规则。
2. **列考点**。从正文抽出 4–8 个可考的点，每个点挂一条 LO。一个 LO 最多出 3 题，超出说明重复。
3. **出基础层**。识记/理解层级，答案能在正文找到依据。至少 3 题。
4. **出提高层**。应用/分析层级，需 2 步以上推理。至少 2 题。含计算题时必须给全已知条件与单位。
5. **出拓展层**。评价/创造层级，无唯一答案。至少 1 题，**必须写明交付物形态**（一页备忘 / 一张矩阵 / 5 分钟陈述）与「合格/优秀」两级评分要点。
6. **配答案**。基础层给参考答案；提高层给答案 + 关键步骤；拓展层给评分要点。
7. **自检**。跑 `python scripts/check_exercise.py <习题.md>`：查三层齐全、题量比例、每题挂 LO、拓展题有交付物与评分要点。
8. **交付**。按 `assets/习题模板.md` 输出，题号全篇连续。

## 输出格式

```markdown
# <课程> 第<单元>单元第<课>课 练习

## 基础层
1. [LO-2-1] 题干
   **参考答案**：…

## 提高层
4. [LO-2-2] 题干（含已知条件与单位）
   **参考答案**：…（含关键步骤）

## 拓展层
7. [LO-2-3] 题干
   **交付物**：…
   **评分要点**：合格 = …；优秀 = …
```

## 质量要求

- 每题必须有 `[LO-x-y]`；无 LO 的题不进教材（硬规则 LX-01）。
- 三层不同质：不得把同一考点换个数字算三遍。
- 计算题的条件要能被题目内部核对：给了产量与单价，就要能算出总额。
- 拓展题必须可验收：老师看完交付物就能判合格与否。
- 题干的组织与人名一律虚构化，与正文的案例命名规则一致。

## 禁止事项

- 不得出正文未覆盖的知识点（超纲）。
- 不得只出一层，或用「谈谈你的理解」这类无法评分的题充数。
- 不得编造数据来源，引用的行业数据须标【待核实】。
- 不得把考试命题（整卷、分值分配、考试时长）纳入本 skill 范围。
