# 写作范式（写正文时照着做）

> 来源：`docs/阶段2c-高质量教材写作范式.md`（通读《信息管理学基础》第三版第 1 章得出）
> 用法：写一节正文前先读本文件，写完对照第五节自检
> 定位：本系列是**教学型**教材（六栏体例），不是专著型。范式取的是推进逻辑，不是栏目清单
> v1.1.5 修订：第 2 问从「并列铺开」改为「**接力**」——依据 `docs/阶段2d`（第 8 章结构化→原型法的衔接原文）

## 一、写一节之前，先回答四个问题

按顺序答完，这一节的骨架就有了：

| 序 | 问题 | 落到哪一栏 |
|---|---|---|
| 1 | **它是什么**——概念、分类、构成要素 | 正文前半 |
| 2 | **此前有过哪些答案**——把多个候选铺开，**让后一个的出场理由来自前一个的缺陷** | 正文中段 |
| 3 | **背后的机制是什么**——为什么是这个形状，而不是别的 | 正文后半 |
| 4 | **条件变了会怎样**——假设失效处、反例、新情境 | 正文末 / 拓展栏 |

常见错误是跳过 2 和 3 直给结论：只有「是什么」加「怎么做」，读者记住了步骤却不知道为什么，换个场景就不会用。

**第 2 问最容易做错的地方不是「给了一种」，而是「给了几种却不接力」。**

| 写法 | 读者得到什么 |
|---|---|
| ❌「常用的方法有 A、B、C 三种。A 是……B 是……C 是……」 | 一张清单。不知道为什么要往下换，也不知道什么时候该换 |
| ✅ A 的缺点（分条、写实）→ 外部条件变了 → 缺点尖锐化 →「**在这种背景下** B 产生，它**摒弃了** A 的做法，**换成**……」 | 一条推理。知道每一种存在的理由，也知道它会在什么时候被淘汰 |

**每个候选之所以存在，理由由上一个候选的缺陷提供。** 这是「接力」，不是「并列」。

**形态按小节类型取，硬要求都是「不只一种」：**

| 小节类型 | 铺什么 | 单个候选怎么写 |
|---|---|---|
| 理论型（概念、流派、模型） | 前人模型 | 来源（谁/哪年/哪刊/**为解决什么问题**）→ 结构 → 贡献 → **局限（2–3 条具体的）** |
| 实务型（决策、方案、路线） | 备选路线 | 别名 → 诞生背景（年代 + 具体症状）→ 基本思想 → 优点（分条）→ **缺点（分条，不少于优点）** |

**每组候选结束必须有收口段**（YY-25）：提炼这一组共性 + 指出谁覆盖谁 + 说明比上一组多了什么。没有收口，读者读完只记得零散条目。

### 候选太多怎么办：先写全景段（YY-26）

一节课要讲一个族，但页数固定。不要「只讲两三个却不提还有别的」（读者以为世界上只有这几种），也不要「每个都展开」（写不完，且主次不分）。

做法是先用一段把家族点全：① 名字点全 → ② 给分类依据 → ③ 声明「大多数情况下综合运用」（防止读者以为要二选一）→ ④ 之后只展开 2–4 个，其余不再提。

> 样本：`8.2.3 信息系统开发方法` 的节导语，一段点了 8 个以上方法、分三类依据，末句「这些开发方法是不断发展变化的，大多数情况下综合运用各种方法」，然后只展开结构化与原型化两种。

## 二、五种段级动作

### A 定义阵列：先说要列，再列，再归纳（YY-18）

三件事缺一不可：

1. **交代目的**：「对什么是 X 迄今尚未有公认的定义。这里仅列举几种有代表性的定义，以使读者对 X 有一个较全面的认识：」
2. **列阵列**：3 条以上结构一致的短句，各自独立成行，句式齐平。不要编号，不要加解释。
3. **归纳**：一段收束，点出这些定义的**分歧点或分类依据**（「有的是从…；有的侧重…；有的反映…」），而不是「以上就是几种定义」。

> 只做第 2 步就是堆砌；做了第 1、3 步才叫写法。

### B 学术史叙事：人—年—刊—结论（YY-23）

讲概念演化时不要抽象转述，把定义放回它诞生的场景：

> 「哈特莱 1928 年在《贝尔系统电话杂志》上发表题为"信息传输"的论文……20 年后香农在同一刊物发表"通信的数学理论"……」

四要素齐备：谁、哪年、在哪发表、提出什么。配脚注到具体文献（见 TY-13）。这条已立为 **YY-23**：四要素缺二即视为不可核查。**权威来自可核查，不来自「著名学者指出」**。

### C 分域扫描：段首定域 + 一例一文（YY-24）

讲「不同领域怎么看同一件事」时：

- **一段一个领域**，段首用状语定域：「在生命科学领域」「在经济领域中」「在哲学层面」
- 段内给**一个具体例子**或**一句可署名的引文**，不泛泛说「都很重视」
- 各段长度接近，形成节奏

反例（不要这么写）：「信息在各个领域都得到了广泛应用，无论是医疗、教育还是金融，都离不开信息。」——正确但零信息量。

### D 表格 + 表后机制解读

表格用于**同构对照**（三列同一组维度），不用来堆数据。

- 表题在上，编号连续
- 单元格内用项目符号列同类项，开放集合末尾可省略
- **表后必接一段解读**，且不复述表内数据，只讲「这张表说明了什么机制」

反例：「如表所示，物质对应物质产品，能量对应能源，信息对应信息产品。」——这是念表格，不是解读。

### E 收口句：提炼共性 + 指出覆盖 + 说明增量（YY-25）

每讲完一组观点/一个领域，用一段收口，三件套：

> 「**由上可见**，在通信领域……取得了丰硕的成果。（提炼共性）这些**也是**香农、维纳等人对信息的共同理解，哈特莱的定义仅仅是香农定义的特殊情形。（指出覆盖关系）**这些认识比**仅仅把信息看做消息要丰富得多、深刻得多。（说明增量）」

收口段的作用是让读者知道「刚才那一堆东西，合起来意味着什么」。没有收口段，读者读完只记得零散条目。

## 三、章/单元层面的收口（TY-16 + TY-19）

单元结束时设三栏，顺序固定：

1. **内容提要**：一段连续散文，按节顺序复述，用分号串联，150–250 字。句式：「介绍了…；将…作为…进行了讨论；阐述了…；最后讨论了…」
2. **本章重点**：3–5 条。每条一个可检验的要点，名词短语或「动词+对象」均可，但同一单元内句式统一。
3. **参考文献**：编号 `[1]`…`[n]`，GB/T 7714，期刊 `[J]`、专著 `[M]`。

## 四、章/节导语（TY-06 四段式）

单元或课的开头，用四段推进，替代「本章介绍……」

| 段 | 动作 | 反例 |
|---|---|---|
| ① | 铺背景：什么条件变了 | 「随着信息技术的发展……」可以，但要具体到**哪个技术、变了什么** |
| ② | **反转**：用「然而」把好处翻成麻烦 | 缺这一段则导语变成宣传语 |
| ③ | 落任务：把麻烦转成要解决的 2–3 件事 | 「本章将介绍……」← 这是预告，不是任务 |
| ④ | 给意义：为什么这件事值得学 | 「具有重要意义」← 空话，要具体到决策后果 |

## 五、写完自检（八问）

- [ ] 四个问题都答了吗？特别是第 2 问（并列候选）和第 3 问（机制）
- [ ] 第 2 问铺了几个候选？只铺一个的话，是不是该铺而没铺？
- [ ] 候选之间是**接力**还是**并列**？读一遍「换下一个候选」的那个转折句——它是不是由前一个候选的缺点引出来的？
- [ ] 每个候选的**缺点**写了几条？比优点少的话，下一个候选就没有出场理由。
- [ ] 候选超过 4 个时，有没有一段全景段把名字点全、给分类依据、声明「多数情况综合运用」？
- [ ] 每组候选结束后，有没有收口段（共性 / 覆盖关系 / 增量）？
- [ ] 段长有没有落差？（YY-02）列举与转折处该短（40–100 字），论证处可到 200 字；通篇匀速读起来是呆板的。
- [ ] 「我们」用了几处？只该有三种：引导分类、说明取舍、引出定义，每节 ≤2 处（YY-05）。
- [ ] 有定义阵列的话，列之前交代目的了吗？列完归纳了吗？
- [ ] 举了例子的话，是「三个并列只给名字」还是「展开了一个」？（YY-20：只给名字）
- [ ] 分域扫描的每段，有没有一句可核查的例证？还是只有「都很重要」？
- [ ] 表格后面那段，是否在解读机制而不是念数据？
- [ ] 讲完一组观点，有没有收口段？收口段有没有指出「谁覆盖谁」「多了什么」？
- [ ] 导语有没有「然而」那个反转？还是通篇正面铺陈？
- [ ] 全文有没有「本章将介绍」「众所周知」「显而易见」这类替代思考的句子？

## 六、逐段过一遍：凭什么（YY-28）

写完之后，从头到尾每段问一句：

> **拿掉这一段，读者会失去什么判断能力？**

- 只是少知道一个事实 → 这段是**资料**。移到附录、或者干脆删掉让学生自己查
- 下次遇到同类问题就无从下手 → 这段是**教材**，留下

这不是修辞要求，是篇幅分配的依据。教材的信息密度不该按字数算，该按**判断密度**算：每千字里有几个「凭什么」。

三种常见的"只有资料没有判断"的段落，见到就改：

| 现状 | 缺什么 | 怎么补 |
|---|---|---|
| 「X 是指……」一句定义，无来源 | 凭什么取这个义项 | 给词源或工具书依据；或指出各家定义的分歧与共识（YY-23、YY-30） |
| 「分为三类：第一类……第二类……第三类……」 | 凭什么这样分 | 补一句「这一层是由……的矛盾所决定的」（YY-29） |
| 「非常重要」「影响深远」 | 重要性无法验证 | 换成规模、年份、版次、用户数（135 个国家、23 版、1876 年） |

## 七、最后一个决定：替读者选一套（TY-20）

如果你的课里出现了多套框架（学界的几种划分、业界的几种模型），**不能停在"以上各有道理"**。

四步走完才算写完：

1. 把别家的框架列出来，每家给一句贡献落点
2. 收口，选定一套作为本课的
3. **说明为什么选它**（涵盖面更广 / 更可操作 / 与前后课衔接）
4. 下面按选定的这套展开

停在「供读者参考」不是谦虚，是把判断责任推给了还不会判断的人。选了就意味着承担：学生学偏了是作者的责任。

## 八、不要照搬的地方

| E1 的做法 | 为什么不照搬 |
|---|---|
| 段落 180–280 字 | 专著型节奏。教学型需要更短段落供停顿与检索，仍按 YY-02 |
| 无习题、无案例框 | 六栏体例的练习栏与案例栏是教学型的必需 |
| 表编号用「表 1-1」 | 改编号体例会连带改脚本正则，收益不抵风险 |
| 正文不引用图表编号 | 我们要求「见表 x」（YY-15），比样本严，保留 |
