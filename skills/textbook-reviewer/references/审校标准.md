## 一、五维评分（每项 1–5 分，加权）

| 维度 | 看什么 | 权重 | 5 分标准 | 3 分标准 | 1 分标准 |
|---|---|---|---|---|---|
| 科学性 | 概念、事实、结论、数据是否准确且可溯源；**论证是否成立**（YY-33 / YY-34 / YY-36④ / YY-39③） | 30% | 所有数据带口径来源；概念定义与主流文献一致；无过度推论；**因果与推论链无越界，结论强度与证据量级匹配，同段无自相矛盾** | 结论正确但个别数据缺来源；或**个别推论强度偏大、个别单因归因未声明，均不影响主结论** | 出现事实错误或未定义概念；或**核心论证存在因果错置、范围越界（个别推全部）、结论超出前提** |
| 体例符合度 | 六栏齐全、顺序正确、篇幅在区间、图表编号规范 | 20% | 全部符合 `体例规范.md` | 栏目齐全但篇幅超区间 ≤20% | 缺栏或栏目顺序错 |
| 学段适切性 | 难度、语言、案例是否对得上本科高年级 / MBA | 20% | 参数落在 `学段适配.md` 区间；难度递进可检出 | 参数基本符合，个别段落过难/过浅 | 用错学段参数（如 MBA 稿件写了完整推导） |
| 练习质量 | 是否分层、是否对齐 LO、是否有参考答案 | 15% | 三层齐全、比例合规、每题挂 LO、拓展题有评分要点 | 分层但比例失衡或少量题缺 LO | 只有一层或无参考答案 |
| 语言规范 | 标点、数字、用词、禁用词；**句法成立性与语域**（YY-31 / YY-32 / YY-35）；**并列与关联词**（YY-37 / YY-38） | 15% | 无禁用词；标点数字全合规；句长段长在限；**主干还原无病句、代词回指唯一、正文无口语化、并列项同层、关联词与实际关系相符** | 有 3–5 处可修问题；或**病句 ≤3 处且不碍理解、个别口语化已在案例引语内、个别并列项杂列** | 大量口语化或违反禁用词表；或**病句 ≥6 处**；或**指代歧义导致段落语义不明** |

**加权公式**：`总分 = Σ(维度分 × 权重)`。建议通过线 **4.0**（SOP 阶段 5）。

## 二、一票否决项（出现任一即判不通过，不进入加权）

| 编号 | 否决项 | 说明 |
|---|---|---|
| SJ-X1 | 思想性、政治性问题 | 涉及国家主权、民族、宗教、历史评价的错误表述 |
| SJ-X2 | 科学性错误 | 概念定义错误、公式错误、数据自相矛盾 |
| SJ-X3 | 版权问题 | 整段改写、拼接或复述样本教材原文；未授权引用 |
| SJ-X4 | 编造事实 | 虚构数据、虚构文献、虚构政策文件且未标【待核实】 |
| SJ-X5 | 违反 GB/T 15834 / 15835 | 系统性标点或数字用法错误（≥10 处） |

> **为什么「论证不成立」（YY-33 / YY-34）不进一票否决。** 长篇书稿里逻辑瑕疵几乎无法归零，设成否决项会让机制失效——一出现就得全盘不通过，审校结论失去分辨力，作者也拿不到「哪几处最要紧」的排序。所以论证问题按**维度扣分**（科学性）+ 进第六节问题清单处理；只有 SJ-X2 那种「数据自相矛盾、公式错误、概念定义错误」的硬错误才否决。这条界线要守住：**推导错一步是质量问题，数据编造是诚信问题。**

## 三、可脚本判定的项（`scripts/check_draft.py` 覆盖）

| 检查项 | 判定 | 依据 |
|---|---|---|
| 六栏齐全与顺序 | 标题匹配 | TY-06 ~ TY-11 |
| 各栏字数是否在区间 | 中文字符计数 | 学段适配参数表 |
| 练习三层是否齐全、比例是否合规 | 小标题匹配 + 计数 | LX-02 |
| 每题是否挂 LO | 正则 `LO-\d+-\d+` | LX-01 |
| 是否含禁用词 | 词表匹配 | 语言风格 §六 禁用词表（总则 YY-01） |
| 是否含「显然/众所周知」等跳跃词 | 词表 | YY-11 |
| 单句是否超 60 字 | 句读切分 | YY-03 |
| 单段是否超字数 | 空行切分 | YY-02 |
| 图表是否有编号与来源 | 正则 `图 \d+\.\d+\.\d+` / `资料来源` | TY-04 / TY-14 |
| 是否出现【待核实】 | 正则 | SOP 阶段 4 |
| 数字是否用空格分节（`1 098`） | 正则 `\d{1,3}(?: \d{3})+` | YY-21 |
| 病句（**A 级，命中即判违规**） | 可枚举格式：`通过…使…`／`原因是…造成的`／`本着…为原则`／`靠的是…取得的`／五组动宾冲突／`减少了 N 倍`／高精度口语词表 | YY-31①②③、YY-35、YY-36① |
| 语言待核（**B 级诊断组，不得用于判不合格**） | 同句「它」与「其／该」并存、顿号并列后代词在其后；因句是正面结果而果句是收缩决策；结论带全称量词而前提无数量或条件限定 | YY-32、YY-33①、YY-34① |

脚本只出「事实性违规清单」，不出分数。分数由 `textbook-reviewer` 依本文件给出，并附证据行号。

> **A 级可直接判，B 级不行。** A 级是格式可枚举、几乎无歧义的，命中即可写「违反 YY-xx」并给改法。B 级是语义上的强信号，依赖上下文——脚本给出定位、原文与判据，由人定判。
>
> **两级都不能反推。** A 级没报，不代表其余句子都通；B 级没报，不代表没有指代或推论问题——YY-32/33/34 的覆盖率本来就有限。把「脚本没报」读成「没有问题」，是这套检测最危险的误用。规则实现见 `scripts/lang_rules.py`（审校与润色共用），误报试金石是 `docs/测试用例/T-03` 与 `C-02` 两份成熟教材正文，在那里面报出即视为规则写坏。
>
> **YY-37~39 不在本节的任何一行里**（v1.3 说明）。三条都是 B 级且**未落成脚本**：顿号并列、「进一步」、「不得不」在成熟教材里大量合法出现，正则只能抓到形状、判不了对等与否，写进去就是制造误报。它们只走第六节的人工项。

## 四、审校报告必备结构

```
1. 结论：通过 / 有条件通过 / 不通过
2. 加权得分：各维度分 + 总分
3. 否决项核查：逐条 X1–X5 是否触发
4. 事实性违规清单：脚本输出，按栏分组
5. 需人工判断的问题：每条给位置 + 问题 + 改法建议
6. 修改后再审要求：需重跑的检查项
```

## 五、审校的边界

- 审校**不改稿**。只出问题清单与改法建议，改稿由作者执行或另起一轮 `unit-writer`。
- 审校**不评「写得好不好」**。文学性评价不进五维，避免主观分污染。
- 审校**必须给出证据位置**（栏目 + 段落序号或引文前 10 字），无位置的意见视为无效。

## 六、只能人工判的项（脚本不覆盖，须写进报告第四节第 5 条）

> 这些条目看的是「这一段说了什么」，不是字符模式。写正则只能抓到「由上可见」这类连接词，而恰恰是只写连接词不写内容的段落最该被判不合格。

| 检查项 | 判定要求 | 依据 |
|---|---|---|
| 导语是否四段推进 | 逐一核对：铺背景 / 反转出问题（把好处翻成麻烦）/ 落任务 / 给意义。缺第②段的，直接判「导语不合格」，不进加权 | TY-06 |
| 正文推进链是否完整 | 是否「概念 → 模式 → 机制 → 边界」四步俱全。**最常见缺陷是缺「模式」**——只给一种模型（或只给一条路线）就往下走，读者会把它当唯一解 | TY-07 |
| 候选之间是接力还是并列 | 找到「换下一个候选」的那个转折句，看它是不是由前一个候选的**缺点**引出来的。写成「常用的方法有 A、B、C」然后逐个介绍，判不合格——读者得到清单，不知道为什么要换 | TY-07 |
| 每个候选的缺点写得实不实 | 缺点条数少于优点、或只写「存在一定局限性」，判不合格。缺点不实，下一个候选就出不来 | YY-27 |
| 候选超过 4 个时有没有全景段 | 有没有一段把全族名字点全、给分类依据、声明「多数情况综合运用」。只讲两三个却不提还有别的，判不合格 | YY-26 |
| 章末参考文献是否只用不列 | 逐条回查 `[n]` 在正文/脚注中有无对应引用。凑书单（列了正文没提过的书）按 TY-19 记不合格 | TY-19 |
| 内容提要是否复述论证 | 提要只该给结论，不该重走推理。出现「首先……然后论证了……」即视为复述 | TY-16 |
| 定义阵列有没有「为什么列」 | 列 3 条以上定义前，是否交代了为什么列、按什么标准列 | YY-18 |
| 学术史四要素是否齐全 | 人 / 年 / 刊 / 结论，缺二即不可核查，记问题 | YY-23 |
| 分域扫描是否落到例证 | 每段是否有具体例子或可署名引文；只有「各领域都重视 X」的判不合格 | YY-24 |
| 收口段是否三件套 | 提炼共性 / 指出覆盖关系 / 说明增量，至少要有前两项 | YY-25 |
| 多套框架并列后有没有选定 | 出现多个框架/模型/流派时，是否选定一套作为本书的，并说明选择理由。停在「以上各有道理，供读者参考」判不合格——这是把判断责任推给读者 | TY-20 |
| 分级分类有没有给成因 | 每一层是否说清了按什么矛盾划分。只有层级没有成因，判「标签式分类」 | YY-29 |
| 争议概念有没有收束 | 是否按「争议 → 共识 → 现实证据 → 分歧」写。只列观点不作收束，判不合格 | YY-30 |
| 逐段问「凭什么」 | 抽 5 段，逐段问「拿掉它，读者会失去什么判断能力」。答「只是少知道一个事实」超过 3 段，判判断密度不足 | YY-28 |

**语病与逻辑（v1.2 新增，判据来自 `语言风格.md` §十一，性质是规范而非抽样，须逐处报出并给改法）**

| 检查项 | 判定要求 | 依据 |
|---|---|---|
| 句子主干是否成立（病句） | 抽 10 句做**主干还原**：删去定状补后是否还剩合法的主谓（宾）。五类必报：成分残缺（`通过…使…`）、搭配不当（`开展…水平`、`提高…机制`）、句式杂糅（`原因是…造成的`、`本着…为原则`）、虚词误用（`对于…来说`套`关于`、`及其`当`以及`）、语序不当（多层定语乱序、状语错位、主客颠倒、关联词位置与主语管辖不符）。**报出时须同时给改法；只写「句子不通」按本文件第五节视为无效意见** | YY-31 |
| 代词是否单向回指 | 段内出现两个以上同性同类候选对象而仍用「它／其／该／此」的，逐处报出，并写明「按上下文指 A 还是指 B」；指不明即判「指代歧义」 | YY-32 |
| 因果是否对得上 | 凡「因为／由于／因此／所以／导致」处，核对三项：时序（因先于果）、必要性（因是果的条件之一）、量级（因能支撑果）。**因果倒置与因果错配必须报**；单因归因须写明还有哪些条件 | YY-33 |
| 结论是否超出前提 | 逐条核对三项越界：范围（个别/全部）、强度（可能/必然）、条件（有/无）。**这是教材最常犯的推理错误：用小样本或单案例得出普遍结论**；条件越界表现为原前提的限定语（「对于数据密集型行业」）在结论句里丢了 | YY-34 |
| 正文是否混入口语 | 区分「叙述」与「模拟说话」：叙述段里出现说话体（`说白了`、`这玩意儿`、`想当年`）即报；案例对话与引文内的口语不报，但须核引号与出处是否完整 | YY-35 |
| 数量表达是否合规、量级是否支撑结论 | 核对：减少是否误用倍数（`减少了 3 倍`必错）、分项之和是否大于总量、百分比是否交代基数、单位是否混用、数值量级能否支撑结论强度 | YY-36 |
| 引文是否被误改 | 抽查对引文的处理：被引作者原句即使违反 YY-31，也不得改动（改动引文即失实），但引号、出处、页码须齐全。发现「引文被顺手润色」的，按编造事实记 SJ-X4 核查 | YY-31 / YY-35 末条 |

**并列、关联词与否定（v1.3 新增，同属 §十一，但三条都是 B 级：只报定位与判据，不作不合格判定）**

| 检查项 | 判定要求 | 依据 |
|---|---|---|
| 并列项是否同层同类 | 抽 5 处顿号并列（≥3 项），逐处问「这些项能被同一条标准同时打勾或打叉吗」。标准混杂（目标／手段／度量并列）、层级错位（上位概念与下位并列）、语法类别不齐（名词夹动宾）三种须报出，并写明**哪一项不在层内**。项本身不对等的，属内容决策，交作者 | YY-37 |
| 关联词是否名实相符 | 凡「然而／但是／反而」（转折）、「进一步／甚至／不仅……更」（递进）、「若…则／只要…就／只有…才」（条件）处，核对前后是否真有该关系。**把并列、递进写成转折是最常见的一类**；条件词错配（`只有…就`、`只要…才`）须逐处报 | YY-38 |
| 否定有没有反转原意 | 查三类：否定冗余（`防止不要`、`避免不再`、`切忌不可`）、否定辖域（`所有…都不` vs `不是所有…都`）、同段判断冲突（前后结论方向相反却无转折交代）。**`不得不`、`不能不`、`不无`、`未尝不` 是正常强调式，不报**；判断冲突须回作者确认删哪一句，不得代选 | YY-39 |

**注意**：这些项一旦判不合格，须在报告里给出**引文前 10 字 + 所在栏 + 段序**。只写「导语写得不好」的意见，按本文件第四节第 5 条视为无效意见。
