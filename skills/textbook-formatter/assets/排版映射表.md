# 排版映射表

> Markdown 结构 → Word 样式。项目可整体替换本表，但六级栏目名不得改。

## 一、标题映射

| Markdown | Word 样式 | 说明 |
|---|---|---|
| `# <单元号>.<课号> <课标题>` | 标题 1 | 一课一个，不出现两个标题 1 |
| `## 导语` / `## 正文` / `## 案例` / `## 思考` / `## 练习` / `## 拓展` | **栏目专用样式** | 六栏固定，不与节标题共用样式 |
| `### x.y.z <小节标题>` | 标题 2 | 正文内小节 |
| `### 基础层` / `### 提高层` / `### 拓展层` | 标题 3 | 仅出现在「练习」栏内 |

**为什么栏目要单列样式**：栏目是体例契约，样式一混，目录里就会把「案例」当成节，读者翻目录找不到章节。

## 二、正文与强调

| Markdown | Word 样式 |
|---|---|
| 普通段落 | 正文（首行缩进 2 字符，1.5 倍行距） |
| `**加粗**` | 正文加粗，仅用于术语首次出现与结论句 |
| `> 引用` | 引文样式（左右各缩进 1 字符） |
| `| 表格 |` | 三线表 |
| `- 列表` | 项目符号，仅用于清单，正文论述不用列表 |

## 三、图表与题注

| 项 | 规则 |
|---|---|
| 表题 | 表上方，居中，小四号加粗，格式 `表 <章>.<节>.<序> <表名>` |
| 图题 | 图下方，居中，小四号加粗，格式 `图 <章>.<节>.<序> <图名>` |
| 资料来源 | 表/图下方，小五号，左对齐，必须存在 |
| 图位占位 | `【图 x.y.z 建议：…】` 保留为独立段落，样式「图位占位」（灰色），交付时列出清单 |

## 四、习题与答案

| 项 | 规则 |
|---|---|
| 题干 | 正文样式，题号用自动编号（不用手动输入"1."） |
| LO 标注 | 紧跟题号，`[LO-x-y]`，小五号，方括号保留 |
| 参考答案 | 单独段落，样式「答案」，小五号，悬挂缩进 2 字符 |
| 交付物 / 评分要点 | 「答案」样式下的子项，不另起标题 |

## 五、引注与参考文献

| 项 | 规则 |
|---|---|
| 页下脚注 | Word 脚注，编号按页重编（①②③），不改成文末尾注 |
| 参考文献 | 章末或书末，样式「参考文献」，悬挂缩进 |
| 文献格式 | `作者. 书名[M]. 出版地: 出版社, 年份.` |

## 六、页面（仅为可读性，不作印刷规范）

| 项 | 默认值 |
|---|---|
| 纸张 | A4 |
| 页边距 | 上下 2.54 cm，左右 3.17 cm |
| 页码 | 页脚居中，正文从 1 起 |
| 目录 | 自动生成，取到标题 2 级（栏目样式不进目录） |

> 以上不是印刷工艺参数。开本、色彩、装订由出版方决定，本表只管"能不能读、能不能自动出目录"。
