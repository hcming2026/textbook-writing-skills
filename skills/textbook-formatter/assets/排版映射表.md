# 排版映射表

> Markdown 结构 → Word 样式。项目可整体替换本表，但六级栏目名不得改。
> **v2 变更**：参数改为按 `docs/阶段2f-排版图表与文字风格实测.md` 的实测值给，不再用 Word 默认值；补章首页、页眉、表格线、图内文字四块。末节列出「与样本不同的地方」及理由——不合样本处都是有意选择，不是遗漏。

## 一、页面与文字

| 项 | 值 | 依据 |
|---|---|---|
| 纸张 | A4（210 × 297 mm） | 项目约定；样本为 159.8 × 230.2 mm 的小 16 开，本系列不锁开本 |
| 页边距 | 上下 2.2 cm，左右：内 2.2 cm / 外 2.6 cm | 内外不等便于装订；样本内白约 10 mm、外白约 16 mm，按其比例放大 |
| **版心宽** | 约 **14.6 cm** | 样本 133.6 mm |
| **每行字数** | **36–40 字** | 样本 36 字；A4 版心可容 40 字，取整不取满 |
| 正文字体 | 中文**宋体**，西文 Times New Roman | 样本正文宋体 |
| 正文字号 | **五号（10.5 pt）** | 样本实测 10.5 pt |
| **行距** | **固定值 17 pt（约 1.62 倍）** | 样本实测 1.65 倍。低于 15 pt 中文发挤；高于 20 pt 一面装不下 900 字 |
| 段首缩进 | 2 字符 | 样本一致 |
| 每面字数 | 约 **1100–1300 字** | 样本 1200–1300 |
| 段间距 | 0（靠首行缩进区分段落，不空行） | 样本无段间距 |

> 为什么把这些数写死：教材的可读性一半来自版面。36–40 字/行是中文的舒适区（超过 45 字，回行会串行）；17 pt 行距让 10.5 pt 的字有约 60% 的呼吸空间。Word 默认「1.5 倍行距」约等于 20 pt，一面只能装 900 字，薄书会厚出一半。

## 二、标题层级

| Markdown | Word 样式 | 字号/字体 | 说明 |
|---|---|---|---|
| `# <章号> <章名>` | 章标题 | 黑体 22 pt，字间加宽 0.25 em | 章首页用；章号另用衬线体 36 pt，见第四节 |
| `# <单元号>.<课号> <课标题>` | 标题 1 | 黑体 16 pt | 一课一个，不出现两个标题 1 |
| `## 导语` / `## 正文` / `## 案例` / `## 思考` / `## 练习` / `## 拓展` | **栏目专用样式** | 黑体 12 pt，段前 12 pt | 六栏固定，不与节标题共用样式 |
| `### x.y <节标题>` | 标题 2 | 黑体 11 pt | 正文内小节 |
| `### x.y.z <目标题>` | 标题 3 | 黑体 10.5 pt | **到这一级为止**，不出现第四级编号 |
| `(1)(2)(3) <段内小标题>` | 正文加粗小标题 | 宋体 10.5 pt 加粗 | 第四层细分**不占编号层级、不进目录** |
| `### 基础层` / `### 提高层` / `### 拓展层` | 标题 3 | 同目标题 | 仅出现在「练习」栏内 |

**为什么栏目要单列样式**：栏目是体例契约，样式一混，目录里就会把「案例」当成节，读者翻目录找不到章节。

**为什么第四级不编号**：样本正文用了 `7.3.1.1`，那行标题只剩编号和六七个字，视觉上很重；而它的目录只收到三级。需要再细分时用 `(1)(2)(3)`，字号与正文相同——正文里分得清，目录里不添乱。

## 三、正文与强调

| Markdown | Word 样式 |
|---|---|
| 普通段落 | 正文（宋体 10.5 pt，首行缩进 2 字符，固定行距 17 pt） |
| `**加粗**` | 正文加粗，仅用于术语首次出现与结论句 |
| `> 引用` | 引文样式（左右各缩进 1 字符，小五 9 pt，行距 15 pt） |
| `- 列表` | 项目符号，仅用于清单，正文论述不用列表 |
| Markdown 表格语法 | 三线表，见第五节 |

## 四、章首页

| 元素 | 做法 |
|---|---|
| 章号 | 西文**衬线体**（Times New Roman）36 pt，常规字重，不用空心字 |
| 章名 | 黑体 22 pt，**字间加宽 0.25 em** |
| 章号与章名 | 同一行，基线对齐，间距 1 字 |
| 分隔线 | 章名下方 0.5 pt 实线，长度 = 版心宽，距章名 1 行 |
| 上部留白 | 章号上方留 4 行空白；**章首页不排页眉** |
| 导语 | 分隔线下 1 行起，首行缩进 2 字，与正文同字号 |
| 资源位 | 若有配套数字资源，置左侧、与导语首段齐平，宽约 2.5 cm（本系列默认无） |

**章首页只做一件事：宣布新的一章开始了。** 不加学习目标框、关键词框、引例框、色块。

## 五、图表

### 5.1 表

| 项 | 规则 |
|---|---|
| 表格线 | **三线表**：顶线 1.5 pt、表头线 0.75 pt、底线 1.5 pt；需要表达分组时加**辅助线**（0.5 pt 横线），不加竖线 |
| 表题位置 | **表号左对齐于版心左缘，表名居中**，同一行，表号与表名之间留 4 字空隙；表题在**表上方** |
| 表题格式 | `表 <章>.<节>.<序> <表名>`，小五（9 pt），**不加粗** |
| 表头 | **不加粗**，与正文同字重——靠线分栏，不靠字重 |
| 单元格对齐 | 短列（类型、维度、指标名）**居中**；长列（说明、内容）**居左**；表头与其列内容对齐一致 |
| 表格宽度 | **窄于版心，左右各缩 2 字，居中** |
| 表注 / 资料来源 | 表下小五，左对齐，**必须存在**（见 5.3） |
| 跨页 | 表头重复；表在跨页处不拆行 |

**表号在左、表名居中**的理由：表号是检索坐标（读者按号找表），表名是内容标签（读者按名判表），两者功能不同，混排会互相干扰。样本正是这样排的。

**三线表而非全框线**：样本用全框线，是因为它有一张四层合并单元格的表，竖线用来撑住分组边界。GB/T 7713.2 推荐三线表并允许加辅助线——辅助线同样能表达分组，版面更干净。这是我们的选择。

### 5.2 图

| 项 | 规则 |
|---|---|
| 图题位置 | 图**下方**，居中 |
| 图题格式 | `图 <章>.<节>.<序> <图名>`，小五（9 pt），**不加粗** |
| 图内文字 | **宋体**（与正文同字体），**小五（9 pt）** |
| 图元 | 线宽 0.5 pt，直角矩形框，**默认无填充**；箭头用细线 + 实心小三角 |
| 图宽 | 不超过版心 80%，水平居中 |
| 间距 | 图与上文 1 行，图与图题 0.5 行 |
| 图位占位 | `【图 x.y.z 建议：…】` 保留为独立段落，样式「图位占位」（灰色），交付时列出清单 |

**图内文字用宋体**：与正文同字体，图看起来是正文的一部分，而不是插进来的一张画。用黑体会让图"跳出来"，读者先看图后看文，反而割裂。

### 5.3 来源与引称

| 项 | 规则 |
|---|---|
| 资料来源 | 图/表下方一行，小五，左对齐。自制写「资料来源：作者绘制」，引用写「资料来源：<出处>, <年份>」 |
| 正文引称 | 图、表在正文中**必须被引称**（「如表 4-1 所示」「如图 7-1 所示」），且在图/表出现**之前**引 |
| 编号 | 三段式 `图 <章>.<节>.<序>`，全册连续，不按页重编 |

> 样本自制的表**不标来源**，我们要求标——教材读者会问"这个分类是谁分的"，专著默认读者知道。这一条我们更严，是有意的。

## 六、引注与参考文献

| 项 | 规则 |
|---|---|
| 页下脚注 | Word 脚注，**编号按页重编，用带圈数字 ①②③**，不改文末尾注 |
| 脚注分隔线 | 版心左侧起，**长约版心 1/4**，0.5 pt |
| 脚注字号 | **小五（9 pt）**，行距 15 pt；编号后空 1 字，**回行顶格不缩进** |
| 文献格式 | 专著 `作者. 书名[M]. 出版地: 出版社, 年份: 页码.`；期刊 `作者. 题名[J]. 刊名, 年, 卷(期): 起止页.` |
| **页码** | **可查页码的必须给**（TY-13）。专著给引用页，期刊给起止页 |
| 外文文献 | 保留原名；作者名缩写加点空格（`D. P. Ballou`） |
| 参考文献 | 章末或书末，样式「参考文献」，悬挂缩进 2 字符 |

## 七、页眉页脚与目录

| 项 | 规则 |
|---|---|
| 页眉（单页/recto） | **章号 + 章名**，右对齐，黑体 9 pt |
| 页眉（双页/verso） | **书名**，左对齐，黑体 9 pt |
| 页眉线 | 页眉下**双线**（0.5 pt + 0.75 pt，间距 1 pt），贯穿版心 |
| 页码 | 页脚居中，小五，正文从 1 起 |
| 目录 | 自动生成，取到**标题 3 级（目）**；栏目样式不进目录；编号与标题间空 1 全角空格，标题与页码间用点线，页码右对齐 |
| 章首页 | 不排页眉 |

**单双页交替不是审美，是装订方向决定的**：读者翻开书时右手边永远是单页。单页放章名（现在在哪一章），双页放书名（拿的是哪本书）。

## 八、习题与答案

| 项 | 规则 |
|---|---|
| 题干 | 正文样式，题号用自动编号（不用手动输入"1."） |
| LO 标注 | 紧跟题号，`[LO-x-y]`，小五号，方括号保留 |
| 参考答案 | 单独段落，样式「答案」，小五号，悬挂缩进 2 字符 |
| 交付物 / 评分要点 | 「答案」样式下的子项，不另起标题 |

## 九、与样本不同的地方（都是有意选择）

| 项 | 样本 | 本表 | 理由 |
|---|---|---|---|
| 表线 | 全框线（有竖线） | 三线表 + 辅助线 | GB/T 7713.2 推荐；辅助线同样能表达分组 |
| 图表资料来源 | 自制表不标 | 必须标 | 教材读者会问"这是谁分的类" |
| 图表引称 | 部分引 | 必须引 | 不引则图表成了孤岛 |
| 第四级标题 | `7.3.1.1` 编号 | `(1)(2)(3)` 不编号 | 四级编号在正文里视觉过重，且目录不收 |
| 开本 | 小 16 开 | A4 | 不锁印刷工艺；便于内部评审与打印 |
| 段长上限 | 无上限（最长 456 字） | 200/180 字（YY-02） | 教学型需要停顿点，但段间要有落差，见 YY-02 |

> 本表只管"能不能读、能不能自动出目录、能不能过审校"。开本、色彩、装订由出版方决定。
