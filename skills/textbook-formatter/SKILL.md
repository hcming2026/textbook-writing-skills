# 排版输出（textbook-formatter）

## 适用场景

- 一课或多课稿件已通过 `textbook-reviewer`，需要落成 Word。
- 需要统一多份稿件的标题层级与栏目样式。
- 需要交付前做一次格式体检。

不适用：内容修改（→ `unit-writer`）、视觉设计（封面/版式创意，本系列不做）、PDF 制作（当前工具链不支持生成 PDF）。

## 输入要求

| 输入 | 说明 | 缺失处理 |
|---|---|---|
| 稿件 | 通过审校的 `.md`，或明确告知「未审校，仅内部排版」 | 必给 |
| 审校报告 | 报告的最后一节结论 | 无报告时提示：未审校稿排出来后不得对外 |
| 排版映射表 | `assets/排版映射表.md`，可项目级定制 | 用默认 |

## 执行步骤

1. **格式体检**。跑 `python ../unit-writer/scripts/check_draft.py <稿件.md>`。仍有 ERROR 时停止排版，回 `unit-writer` 修稿——带着错误排版只会把问题固化。
2. **确认审校结论**。读审校报告，结论为「不通过」时不排版；为「有条件通过」时先列出条件是否已闭合。
3. **套映射表**。按 `assets/排版映射表.md` 把 Markdown 结构映射为 Word 样式：`#` → 标题 1（章）、`##` → 标题 2（栏目标题或节）、`###` → 标题 3（小节）。**栏目标题（导语/正文/案例/思考/练习/拓展）必须用专用样式**，不能与节标题混用，否则目录会乱。
4. **补章末三栏**。章末是**章级产物**，`unit-writer` 按课写稿时覆盖不到，由本环节统一补齐并核对（合册排版必做，单课排版跳过）。每章末尾按固定顺序放三栏：
   - **本章内容提要**：连续散文（不是条目堆叠），按节顺序用分号串联，≤600 字，只给结论不复述论证（TY-16）
   - **本章重点**：编号 3–5 条，每条一个要点（TY-16）
   - **本章参考文献**：`[1]`–`[n]`，GB/T 7714，**必须是正文或脚注里实际引用过的**，不得凑书单（TY-19）

   三栏素材从各课稿件里汇总，不要另写新内容——排版环节不创作（见禁止事项）。
5. **处理图表**。图题在下、表题在上；编号保留三段式；「资料来源」用小一号字号紧随图表。图位说明（`【图 x.y.z 建议：…】`）保留为占位文字，不转成图片。
6. **调文档工具**。本地 Word 生成与编辑走 `workbuddy-docx`（从零成稿）或 `workbuddy-local-office-edit`（就地编辑），本 skill 只出结构与样式指令，不自行拼 XML。
7. **核对**。生成后逐项核对：标题层级、栏目样式、章末三栏齐全、图表编号连续、资料来源齐全、目录能自动生成。
8. **交付**。给出页数、图表数、参考文献条数、以及"仍为占位"的图位清单。

## 输出格式

- 交付物：`<课程名>-<单元号>-<课号>.docx`（单课）或 `<课程名>.docx`（合册）
- 同步产出 `排版核对单.md`：逐项打勾，未通过项写明原因

## 质量要求

- 层级不乱：章 → 节 → 目三级，栏目标题单独成级，不嵌套错位。
- 样式统一：同类内容用同一样式，不手动加粗代替标题。
- 编号连续：图、表编号全册连续，不按页重编。
- 引注落位：页下脚注留在页下，不改成文末列表。
- 图位显式：未出图的占位必须保留文字，不能悄悄删掉。
- 章末齐全：合册交付时每章都有提要 / 重点 / 参考文献三栏，缺一即退回（TY-16、TY-19）。

## 禁止事项

- 不得在排版阶段改动正文内容（改一个字也得回 `unit-writer`）。
- 不得代做封面、开本、色彩、装订等印刷设计。
- 不得生成 PDF（工具链不支持，且非本系列范围）。
- 不得把「资料来源」省略或合并进表注。
