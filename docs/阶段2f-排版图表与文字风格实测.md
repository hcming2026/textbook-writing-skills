# 排版、图表、文字风格实测

> 对象：E1《信息管理学基础》（第三版），科学出版社，扫描件 465 页
> 方法：300 dpi 渲染后做**像素级测量**（墨迹投影求版心与行距），关键局部裁切放大读版式；不靠目测估计
> 与前三篇的分工：2c/2d/2e 讲**写什么、为什么这样写**；本篇只讲**排成什么样子**——版心、字号、行距、表格线、题注位、脚注、文字风格的可量化特征
> 页码换算：PDF 页 = 书内页 + 19
> 日期：2026-10-24

## 一、版面：硬参数（实测）

用 300 dpi 渲染后取墨迹投影，得版心边界与行带位置，逐项换算：

| 项 | 实测值 | 换算 | 备注 |
|---|---|---|---|
| 页面 | 453 × 652.6 pt | 159.8 × 230.2 mm | 扫描后可能被裁切归一，不作开本断言 |
| 版心宽 | 1578 px（三页一致） | **133.6 mm** | 左右镜像，奇偶页互换 |
| 版心高 | 约 2690–2740 px | 约 228 mm | 含页眉与页码区 |
| 正文字号 | 墨迹高 43–44 px | **10.5 pt（五号）** | 汉字方块，字高≈字宽 |
| 行距（基线间距） | 72.0 px | **17.3 pt ≈ 1.65 倍** | 三页实测 71.5–72.0，极其稳定 |
| **每行字数** | 1578 ÷ 43.75 | **36 字** | 1578/36 = 43.8 px，与字高吻合 |
| **每面行数** | 33–37 行 | — | 表多的页少，纯文字页 36–37 |
| **每面字数** | 36 × 34 | **约 1200–1300 字** | 一页 ≈ 一篇短文 |
| 段首缩进 | 2 字 | 21 pt | 与首行缩进 2 字符一致 |
| 左/右白边 | 约 117 px / 192 px（奇偶互换） | **约 10 mm / 16 mm** | 装订侧窄、切口侧宽；因扫描裁切，具体值仅供比例参考 |

**为什么记这些数**：它们决定了教材的"呼吸"。36 字/行、34 行/面，意味着一屏手机大小的版面里放 1200 字；一个 250 字的段落只占 7 行，读者一眼能扫完。若把字号改到 10 pt、行距压到 1.3 倍，同样版面能塞 1600 字，但每行 38 字、行距 13.7 pt，中文会显得密不透气——**这是教学型教材和学术专著体感差别的物理来源**。

## 二、章首页版式

书 117（第 4 章首页）版式拆解：

| 元素 | 做法 |
|---|---|
| 章号 | **衬线体**（Times 类）数字，约 36–40 pt，常规字重，不用空心 |
| 章名 | **黑体**，约 20–22 pt，**字间加宽**（每字间约 0.25 em 空隙） |
| 章号与章名 | **同一行**，基线对齐，间距约 1 字 |
| 分隔线 | 章名下方一条 **0.5 pt 细线**，长度约等于版心宽，距章名约 1 行 |
| 二维码 | **左侧**，与导语首段齐平，尺寸约 4–5 行高，悬在版心左缘外（占用部分左白边） |
| 导语 | 另起段，**首行缩进 2 字**，与正文同字号同字体 |
| 上部留白 | 从页眉到章号约 4–5 行空白；**章首页不排页眉** |

这一套的价值：**章首页只做一件事——宣布"新的一章开始了"**。没有学习目标框、没有关键词框、没有引例框、没有色块。省下的空间给了上部留白和导语，读者翻到这页会自然放慢。

## 三、标题层级与目录

样本用**四级编号**，但目录只收到**三级**：

| 级 | 样例 | 字体字号 | 目录 |
|---|---|---|---|
| 章 | `4 信息获取` | 黑体 20–22 pt + 衬线章号 | 进，黑体，缩进 0 |
| 节 | `4.1 信息源的概念` | 黑体 12–14 pt | 进，宋体，缩进 2 字 |
| 目 | `4.3.1 信息质量评价的一般维度与指标` | 黑体 10.5–11 pt | 进，宋体，缩进 4 字 |
| 小目 | `7.3.1.1 信息需要与信息需求` | 黑体 10.5 pt | **不进目录** |
| 段内分点 | `(1) 信息政策的含义和内容` | 宋体 10.5 pt，**不占编号层级** | 不进 |

**目录版式**：编号与标题间空 1 全角空格；标题与页码之间用**点线（……）**连接，页码**右对齐**；章标题左侧另有一个小图标（标记该章有配套数字资源）。

**这一处值得直接学的**：需要第四层细分时，样本不新开一级编号，而是用 **`(1)(2)(3)` 的段内分点**——字号与正文相同、不占层级、不进目录。这样正文里既有细分，视觉上又不会出现「7.3.1.1」这种一行只有编号和六个字的空标题。

## 四、表：全框线，表号在左，表名居中

表 4-1 与表 7-1 的版式完全一致：

| 项 | 实测做法 | 我们的做法 | 差异 |
|---|---|---|---|
| 表格线 | **全框线**：表头下一条横线，**每一列之间都有竖线**，分组之间加横线 | 三线表 | 见下 |
| 表号位置 | **左对齐于版心左缘**（`表 4-1`） | 表题整行居中 | 不同 |
| 表名位置 | **居中**，与表号之间留大间距 | 与表号连写 | 不同 |
| 表头 | **不加粗**，与正文同字重 | 加粗 | 不同 |
| 单元格对齐 | 短列**居中**（类型/维度/指标），长列**居左**（评价内容、后台工作） | 未规定 | 应补 |
| 表格宽度 | **窄于版心**，左右各缩约 2 字，居中 | 未规定 | 应补 |
| 资料来源 | **无**（自制表不标） | 必须有「资料来源：作者绘制」 | 我们更严 |
| 表注 | 无 | — | — |
| 正文引称 | 有：「（如表 7-1 所示）」 | 必须有（YY-15） | **一致**，不是我们更严 |

**关于全框线 vs 三线表**：样本用全框线，是因为表 4-1 有四层合并单元格（信息质量 → 四个维度 → 14 个指标），竖线用来撑住分组边界。GB/T 7713.2 推荐三线表，但**允许加辅助线**。所以我们的选择是：**三线表 + 需要时加辅助线**，不用全框线——既合规范，也能表达分组。这一条不改规范库，写进排版映射表。

**一处需要修正的旧判断**：`阶段2c` 记「正文引用图表：本页未见引用句……我们的 TY-15 比样本严」。现在读到表 7-1（「如表 7-1 所示」）与图 7-1（「如图 7-1 所示」），样本**也引称**，只是不逐张都引。所以 YY-15 与样本是**一致的**，不是更严。旧判断的措辞已在新文档更正。

## 五、图：题在下，图内用正文同款字体

图 7-1（信息需要的层次结构状态）：

| 项 | 实测做法 |
|---|---|
| 图题 | 图**下方**，居中，`图 7-1 <图名>`，字号小五 |
| 图内文字 | **宋体**（与正文同字体），约 9 pt（小五） |
| 图元 | 细线矩形框（0.5 pt），**无填充色**，直角；箭头为细线 + 实心小三角 |
| 图宽 | 约版心 60%，**水平居中** |
| 与文间距 | 图与上文约 1 行，图与图题约 0.5 行 |
| 资料来源 | 无 |
| 正文引称 | 有：「如图 7-1 所示」 |

**图内文字用宋体而不是黑体**，这一点值得注意。国内不少教材图内用黑体以求醒目，这本书用宋体小五——好处是图与正文视觉连续，图看起来是"正文的一部分"而不是"插图"；代价是小字号下宋体略糊。我们的映射表按宋体小五走，与样本一致。

## 六、脚注与参考文献

| 项 | 实测做法 |
|---|---|
| 分隔线 | 脚注上方一条**短横线，长约版心的 1/4**，0.5 pt |
| 编号 | **带圈数字 ①②③**，按页重编（与正文上标对应） |
| 字号 | 约 **9 pt（小五）**，比正文小一号；行距约 1.2 倍 |
| 缩进 | 编号后空约 1 字，**回行顶格不缩进** |
| 文献格式 | `作者. 题名 [J]. 刊名, 年, 卷(期): 起止页.` |
| 专著格式 | `作者. 书名 [M]. 出版地: 出版社, 年份: 页码.` |
| **页码** | **给**（`1985, 31(2): 150-162`、`2014: 320`） |
| 外文文献 | 保留原名，作者名缩写加点空格（`D. P. Ballou`） |
| 页码 | 页面底部**居中** |

**这一处我们要改**：TY-13 原先没要求页码，理由是"教材比专著松"。实测样本**每一条都带页码或起止页**。教材引用不带页码，学生回查不到，等于没引。已在 v1.1.7 给 TY-13 补上"可查页码的应给页码"。

## 七、文字风格：可量化的几项

### 7.1 段落长度随内容类型变，不是匀速

从 6 个正文页逐行测行带与段起缩进，估出每段字数（跨页段落会被切断，故只看分布）：

| 页 | 内容类型 | 段长（字） |
|---|---|---|
| 书 124 | 指标列举（四维度各一段） | 37 / 44 / 45 / 83 / 85 / 98 |
| 书 123 | 文献综述（多套框架并列） | 45 / 49 / 73 / 74 / 75 / 158 / 201 / 225 |
| 书 158 | 方法特征 + 工具介绍 | 48 / 129 / 164 / 253 / 257 / 259 |
| 书 157 | 理论基础（四个理论逐个） | 436 / 456 |

结论：**段长是内容类型的函数**——列举型 40–100 字，论述型 130–260 字，理论综述型 400 字以上。全篇匀速（每段都 200 字左右）反而显得呆板。

这修正了我们对 YY-02 的理解：200 字上限不是"每段都写到 200"，而是**上限**；段与段之间要有落差，长段承担论证，短段承担列举与转折。

### 7.2 「我们」是用的，不是不用

`阶段2c`/v1.1.3 记「本土权威教材 E1、E4 全篇不用『我们』」，据此把 YY-05 改成「可用但非必需」。**这条判断是错的**，实测频繁出现：

> 「**我们**可以将信息交流划分为下列几种形式」（书 44）
> 「**我们**既没有可能也无必要去利用所有的信息检索工具」（书 233）
> 「在认识信息需求之前，**我们**先要了解一下信息需要」（书 281）
> 「**我们**把意识到的信息需要定义为信息需求」（书 281）

约 **每节 1–2 处**，全部用于三种场合：**引导分类 / 说明取舍 / 引出定义**。这是最典型的教学语气——把作者和读者放在同一侧。

所以 YY-05 的正确表述不是「可用但非必需」，而是：**本科高年级正文可用「我们」，限于三种场合（引导分类、说明取舍、引出定义），每节不超过 2 处；不用「你」**。已在 v1.1.7 改正。

（附带一句自省：这已经是第四次把「某几页没看到」写成「全篇不用」。判据还是那条——下结论前先问"我看了几页"。）

### 7.3 引注密度

| 页 | 脚注数 | 该页字数 | 密度 |
|---|---|---|---|
| 书 123 | 3 | 约 1250 | 每 400 字 1 个 |
| 书 158 | 2 | 约 1300 | 每 650 字 1 个 |
| 书 117 | 1 | 约 1200 | 每 1200 字 1 个 |

**每 400–1200 字一个引注**，即每页 1–3 个。教材的权威感有相当一部分来自这个密度——不是"引了名著名言"，而是**每个有争议的地方都有人接着**。

### 7.4 数字与标点

| 项 | 做法 | 例 |
|---|---|---|
| 年份 | 阿拉伯数字，不加引号 | 1876 年、2011 年第 23 版、2000 年 |
| 规模数字 | 阿拉伯数字 + 量词 | 135 个国家、30 种语言、近 1000 个类目、16 个二级指标 |
| 引号 | **弯引号**“ ”，不用「」 | “信息传输”、“5W” 模式 |
| 括号 | 半角外文词用**全角括号包裹** | 信息检索系统（Information Retrieval System，简称 IRS） |
| 书名号 | 期刊/著作用《》，篇名用“” | 《贝尔系统系统电话杂志》 |

### 7.5 术语首现的处理

样本在术语首现处**高密度**给英文原名或缩写，之后全用中文或简称：

> 信息系统（**Information System**）
> 信息检索系统（Information Retrieval System，**简称 IRS**）
> 《杜威十进制分类法》（**Dewey Decimal Classification，简称 DDC**）
> 香农（**C. E. Shannon**）与维弗（**W. Weaver**）

与 TY-12 一致。差异在我们要求「中文全称 + 英文原文 + 一句话定义」三者齐全；样本常**只给中英对应、定义放在下一句**。我们更严，保留。
