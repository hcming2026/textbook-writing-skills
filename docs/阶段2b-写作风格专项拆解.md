## 四、提炼结论

### 共性（→ 强制规则）

1. **概念引入用「阵列 + 归纳」**：先给一组结构一致的短单元（定义句 / 问句 / 步骤），每单元独立成行，再用一段归纳收束。四套里三套有实证，E2 以设问变体呈现。→ 新增 YY-18
2. **并列举例不展开**：出现「比如/例如」时给 3–5 个平行实例，逐个只说名字，展开其中任何一个都是偏离。→ 新增 YY-20
3. **公式后必须逐项释义**：公式独立成行，「式中：」引导，每个符号一行。→ 新增 YY-19
4. **数字不用空格分节**：E2 的「1 098」是英文排版直译，中文规范不如此处理。→ 新增 YY-21

### 特色（→ 可选风格，不强制）

1. **第二人称「你」只出现在翻译教材的导入与案例中**，本土三套均不用。→ 修订 YY-06，把「你」的使用限定在 MBA 情境导入，且不强制。
2. **「我们」不是本科必备**：本土权威教材 E1、E4 全篇不用，E3 用来表达推导立场。原 YY-05 要求「本科用我们引导推导」与证据不符，改为「允许，不强制」。
3. **长句容忍度与学段无关、与文体有关**：理论阐述型（E4）40–70 字常见，方法型（E3）30–50 字。原 YY-03 的 60 字上限对 E4 偏严，放宽到「理论阐述段 80 字，全课 ≤3 处」。
4. **学习目标可写成问句**（E2）也可写成动词式（本土惯例）。二者取一，全册统一。→ 写入 YY-22
