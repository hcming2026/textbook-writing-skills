# 高质量教材写作范式（基于 E1 通读）

> 样本：马费成、宋恩梅、赵一鸣《信息管理学基础》（第三版），科学出版社，465 页（扫描件，渲染识读）
> 读法：第 1 章章首页 → 1.1.1 定义 → 1.1.1 学术史 → 1.1.1 分域 → 1.2.1 对照表 → 章末三栏（书内 p1–p4、p14、p41–p42、目录 p2–p3）
> 与 `阶段2b` 的区别：2b 是四本书浅扫找共性，本篇是**一本书的纵向通读**，看的是段落怎么推进、章怎么收口
> 日期：2026-10-24

## 一、章级结构：四段式导语 + 三栏收口

### 章导语（书内 p1）

无学习目标框、无关键词框、无引例框，章标题后直接一段导语。这段导语是严格的四段推进：

| 位置 | 动作 | 例句（≤30 字摘录） |
|---|---|---|
| ① 铺背景 | 时代/技术条件已经变化 | 「随着当代信息技术的高度发展和广泛应用」 |
| ② 反转出问题 | 用「然而」把好处翻成麻烦 | 「然而，信息量指数增长……又反过来危及人类的生存和进步」 |
| ③ 落学科任务 | 把问题转成学科要干的三件事 | 「需要我们进一步认识信息、研究信息、管理信息」 |
| ④ 给课程意义 | 说明为什么学这门课 | 「为开发信息和利用信息提供理论方法」 |

这套写法的价值在于：**读者在读到第一个定义之前，已经知道这门学问为什么必须存在**。全段约 200 字，没有一句「本章介绍……」的预告式空话。

### 章末三栏（书内 p41–p42）

| 栏目 | 形式 | 实测 |
|---|---|---|
| **本章内容提要** | 一整段连续散文，按节顺序复述，用分号串联 | 约 200 字，句式是「介绍了…；将…作为…进行了讨论；阐述了…；分析了…；最后讨论了…」 |
| **本章重点** | 编号 1–4，每条一个要点 | 4 条。第 1 条带动词（「结合实际的应用领域，认识和理解……基本概念」），第 2–4 条是纯名词短语（「信息管理研究及实践的多重视角及不同视角的特点」） |
| **本章参考文献** | 编号 [1]–[14]，GB/T 7714 | 期刊 `[J]`、专著 `[M]`，中文条目给到出版社与年份，英文给到卷期页 |

**注意：本书第 1 章没有思考题，也没有练习题。** 这不是遗漏——E1 属「学科专著型教材」，栏目极简。它靠提要与重点收口，不靠习题检验。

### 这一条与我们体例的关系

本项目的六栏体例（导语→正文→案例→思考→练习→拓展）是**教学型**教材的形态（对应 Laudon 那一侧），与 E1 的专著型不是一回事。两类可以并存，但**不能混用**：一本教材里既放大量案例框又只写提要式收口，会显得两头不靠。

可借鉴的是**推进逻辑**，不是栏目清单。

## 二、节级推进链：概念 → 模式 → 机制 → 新情境

第 2 章的节顺序是判断范式的关键证据：

```
2.1 信息交流的基本概念   分类 / 含义与特征 / 行为 / 条件和要素
2.2 信息交流的模式       香农-维弗 / 拉斯韦尔 5W / 施拉姆 / 维克利 S-C-R / 米哈依洛夫
2.3 信息交流机制         社会信息流的形成 / 交流中的「栈」/ 直接交流与社会代理 / 传递模式
2.4 网络信息交流         兴起 / 模式及特点 / 移动 / 网络环境下的科学交流
```

四步各司其职：

1. **立概念**：先把「是什么、分几类、由什么要素构成」讲清，不急于给模型。
2. **列模式**：把学界已有的五个经典模型铺开，各给提出者与适用边界。这一步的作用是让读者知道「人类已经想到过哪些答案」——**而且要让他们知道为什么需要下一个**。

   > **勘误（2026-10-24，据 `阶段2d`）**：此处原写「**并列**铺开」。这个判断是从**目录**推出来的——本篇只读了书内 p41–p42，2.2 的正文（书 49–51）没读。读完正文才发现 E1 写的是**接力**：讲完香农模型的局限（语义与语用关注少、单向线性、未考虑反馈）→ 这些局限成为下一个模型出场的理由。
   >
   > **并列产出清单，接力产出推理。** 读者要的是后者。规则层面的修正是 TY-07，详见 `阶段2d` §零与 §三。
   >
   > 这条勘误的价值不在改一个词，而在标注一类错误：**只看目录就下判断**。目录能告诉你"有哪些"，告诉不了你"怎么衔接"。
3. **挖机制**：模式只描述形状，机制回答「为什么是这个形状」——社会信息流怎么形成、中间为什么需要「栈」（节点）。
4. **落到新情境**：网络出现后，前三个模型的哪些假设失效了。

第 3 章「信息分布」同构：马太效应（现象+负面影响+数学模拟）→ 离散分布规律（布拉德福德/齐夫/洛特卡/普赖斯）→ 生产者分布 → 时间分布（指数增长/逐渐过时）。**现象 → 规律 → 定律 → 变化**。

### 可迁移的写法

写一节时先问四个问题，按序回答，就是一个完整的节：

> 它是什么（概念）→ 前人给过哪些解释（模式）→ 背后的机制是什么（机制）→ 条件变了会怎样（边界/新情境）

## 三、段级五种动作

这五种动作在第 1 章反复出现，可直接当写作手法清单用。

### A. 定义阵列 + 目的交代 + 归纳

**先交代为什么要列一堆定义**，再列，列完再归纳——这是最关键的一步，缺了它读者会困惑于「为什么突然堆定义」。

> 「然而，对什么是信息迄今却尚未有公认的定义。这里，仅列举一些比较典型、比较有代表性的定义，以使读者对信息的概念有一个较为全面的认识：」（p1）
>
> 接着 20 条独立成行的短定义：「信息就是信息，既不是物质也不是能量。」「信息是事物之间的差异。」「信息是系统的复杂性。」……（p1–p2）
>
> 然后归纳：「这些对信息的理解，有的是从哲学角度出发，探讨信息的本质属性；有的侧重于信息在传递过程中的形态；有的反映了信息对于接受者而言所产生的效用。」（p2）

### B. 学术史叙事：人—年—刊—结论

不空讲定义，而是把定义放回它诞生的场景里。

> 「这一领域的奠基之作当推哈特莱 1928 年在《贝尔系统电话杂志》上发表题为"信息传输"的论文。」→「20 年后（即 1948 年），通信专家香农在《贝尔系统电话杂志》上发表了一篇题为"通信的数学理论"的论文」→「控制论的奠基人维纳则把信息看做广义通信的内容。」（p3）

每一步都给：**谁、哪年、在哪发表、提出了什么**，并配脚注到具体文献。权威感来自可核查，不来自形容词。

### C. 分域扫描：段首定域 + 一例一文

讲「信息在各领域的不同理解」时，**一段一个领域，段首用状语定域，段内给一个具体例子或一句引文**：

> 「在**生命科学领域**，动物界与植物界的信息交换……例如生物体内的核酸分子（分为 DNA 和 RNA）就是通过自我复制，把遗传信息一代代传下去」（p4）
> 「在**科技领域**，科技信息工作成为科技工作的重要组成部分……」（p4）
> 「在**经济领域**中，人们关注的是企业、商品（价格）、顾客、市场等方面的信息……美国著名经济学家肯尼思·J. 阿罗在其著作《信息经济学》中提道：……」（p4）
> 「信息的普遍性和广泛性也引起了**哲学家**们的关注……」（p4）

这种写法避免了「各领域都重视信息」这种正确但无信息量的空话。

### D. 对照表 + 表后机制解读

书内 p14 的表 1-1 用三列同构对照（物质／能量／信息），每列内部用项目符号列同类项，末尾用省略号表示开放集合：

| 物质 | 能量 | 信息 |
|---|---|---|
| 物质产品的生产、加工和分配领域 | 能源的生产、加工和分配领域 | 信息的产生、加工收集、存储和分配领域 |

表后紧接一段解读，**不复述表格数据**，而是给出机制：

> 「信息流反映物质能量流的运动，社会借助信息来控制物质能量流的运动，左右它们的运动方向，进行科学分配，实行有效管理。」（p14）

### E. 收口句：由上可见 + 提炼共性 + 指出超越

每讲完一个领域/一组模型，有一段收口，句式高度稳定：

> 「**由上可见**，在通信领域所展开的对信息的研究取得了丰硕的成果。在这里，信息被看做有序程度（或组织程度）的度量和负熵……这些**也是**香农、维纳、布里渊等人对信息的共同理解（哈特莱的信息定义仅仅是香农定义的特殊情形）。**这些认识比**仅仅把信息看做消息或通信的内容要丰富得多，深刻得多。」（p3）

三件套：**提炼这一组的共同点 → 指出组内谁覆盖谁 → 说明这一组比上一组多了什么**。

## 四、引证与体例（实测）

| 项目 | E1 的做法 | 与本项目规则的关系 |
|---|---|---|
| 脚注 | 页下脚注，给到作者、书名/篇名、出版地、出版社、年份，**部分带页码**（`1983: 12-14`） | 我们的 TY-13 原未要求页码，比样本松。**v1.1.7 已补**（见 `阶段2f` 实测：样本每条脚注都带页码） |
| 文献类型标识 | 期刊 `[J]`、专著 `[M]`，英文条目保留原名 | 一致 |
| 表题位置 | 表**上方**，编号「表 1-1」（章-序式） | 我们要求题在上，一致；但编号体例我们用的是「表 2.1.1」式，样本用「章-序」式 |
| 表后解读 | 必有，且不复述数据 | 与 YY-17 一致 |
| 正文引用图表 | **本页未见引用句**，表格直接插在段落间 | 我们的 YY-15 要求必须「见表 x」。**v1.1.7 更正**：读到表 7-1／图 7-1 前均有引称（「如表 7-1 所示」「如图 7-1 所示」），样本也引，只是不逐张都引——我们是更严，但差距没原先写的大 |
| 术语 | 首现给英文原名或缩写（DNA/RNA、Bioinformatics、IM） | 与 TY-12 一致 |

**判断**：我们有三处规则**比这本权威教材更严**（引注页码、图表必须被正文引用、自制表须标来源）。这不算错——教材比专著更需要可教学性——但要清楚这是我们的选择，不是行业通例。若作者抱怨「太严」，答案应是「这是教学型教材的取舍」，而不是「书上没这么写所以可以不做」。

## 五、我们该学什么、不该学什么

**该学（已写入规则，v1.1.4）**

| 学什么 | 落成哪条 | 改动性质 |
|---|---|---|
| 章导语的「背景→反转→学科任务→课程意义」四段式，替代「本章介绍……」的空预告 | **TY-06**（改写） | 原条目只要求「一个情境 + 末句提问」，未规定推进顺序，写出来仍可能是正面铺陈 |
| 节的四问推进链：是什么 → 前人怎么解释 → 机制 → 边界/新情境 | **TY-07**（改写） | 原为「概念→机制→方法→边界」，**缺了「模式」这一步**——即「前人给过哪些答案」。跳掉它，读者只知道一种模型，把它当成唯一解 |
| 章末三栏：内容提要 / 本章重点 / 本章参考文献 | **TY-16**（改写）+ **TY-19**（新增） | 原 TY-16 只要求「小结 + 复习题」，无参考文献栏；E1 把参考文献当章末固定件 |
| 定义阵列之前先交代「为什么列」 | **YY-18**（改写） | 原条目只要求阵列与归纳，未要求「列之前交代目的」 |
| 学术史叙事给到「人—年—刊—结论」 | **YY-23**（新增） | 原规范只有 TY-13 管脚注格式，没管正文里怎么讲来历 |
| 分域扫描时用段首状语定域，段内给一例一文 | **YY-24**（新增） | 原规范无对应条目 |
| 收口句三件套：提炼共性 + 指出覆盖关系 + 说明增量 | **YY-25**（新增） | 原 YY-17 只管「不复述数据」，没管收口段该写什么 |

**不该照搬**

1. **段落长度**：E1 段落普遍 180–280 字，比我们 YY-02 的 200 字上限长。这是专著型的舒缓节奏，教学型教材需要更短的段落供停顿与检索。**不改我们的段限。**
2. **无习题**：E1 靠提要收口。我们的六栏体例含练习栏，这是教学型的必需，不改。
3. **无案例框**：E1 把案例融在正文叙述里（阿罗、生物信息学），不单独起框。我们单独设案例栏是为了让案例可被讨论，保留。
4. **表编号「1-1」式**：改编号体例会连带改脚本正则，收益不抵风险。维持现状。

## 七、用自家范文反查规则（改完规则后做的一次对照）

规则写完不等于对。把 v1.1.4 的 TY-06 / TY-07 拿去过一遍 `skills/unit-writer/assets/范文-u2-l3.md`（本系列自带的 0/0 范文），暴露出**两处过度具体**：

| 规则原措辞 | 范文实际怎么写的 | 问题 | 改法 |
|---|---|---|---|
| TY-06「用**「然而」**把好处翻成麻烦」 | 导语用「销售部门天天抱怨查不到库存，财务部门却坚持账实相符」——**部门立场对立**，没有「然而」 | 把字面连接词当成了动作，范文会因此被判不合格 | 改为「反转出问题」，列出三种实现：E1 的「然而」／立场对立／方案互斥 |
| TY-07「铺**前人模型**」 | 该课是决策型，2.3.1 铺的是「一次性替换 / 分步替换 / 封装加中台」三条**路线**，不是学术模型 | 把理论型小节的做法当成了通则 | 改为「并列铺开多个候选」；形态按小节类型取，硬要求统一为「不只一种」 |

**教训**：从样本里提炼规则时，很容易把「这个样本用了什么」写成「必须用什么」。前者是字面，后者是动作。判据是——**换一个好作者用别的写法达成同一效果，这条规则会不会误伤他？** 会误伤，就说明规则还停在字面。

这条对后面所有从样本新增的规则都适用。YY-24 也已据此放宽：要求的是「段首定域 + 段内有例证」，不要求必须写成「在……领域」。
